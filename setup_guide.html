GATES Workshop Setup Guide

System Requirements

SoftwareVersion
VS CodeLatest
MinicondaLatest
Python3.12
Node.jsLTS (Recommended)

1. Install Visual Studio Code

Windows

  1. Download VS Code from https://code.visualstudio.com/Download.
  2. Run the installer.
  3. Recommended options:
    • Add to PATH
    • Open with Code
  4. Launch VS Code.

macOS

  1. Download VS Code from the same link above.
  2. Open the downloaded ZIP.
  3. Drag Visual Studio Code.app into the Applications folder.
  4. Launch VS Code.

2. Install VS Code Extensions

Open the Extensions panel (Ctrl+Shift+X on Windows or Cmd+Shift+X on macOS).

Install:

  • Python (Microsoft)
  • Jupyter (Microsoft)

Marketplace links:

  • Python Extension
  • Jupyter Extension

3. Install Miniconda

Download:

https://www.anaconda.com/download/success

Windows

  • Install for Just Me.
  • Keep default installation directory.
  • Leaving "Add Miniconda to PATH" unchecked is recommended.
  • Open the Anaconda Prompt after installation.

macOS

Install Miniconda then initialize Conda if necessary:

conda init

Restart Terminal and verify:

conda --version

4. Create the Workshop Environment

conda create -n gates_workshop_env python=3.12 -y

conda activate gates_workshop_env

python --version

5. Open the Workshop Folder

Open VS Code and choose:

File → Open Folder...

6. Install Workshop Requirements

conda activate gates_workshop_env

cd path/to/workshop

pip install -r requirements.txt

7. Select the Notebook Kernel

  1. Open the workshop notebook (.ipynb).
  2. Click Select Kernel in the upper-right corner.
  3. Select Python Environments.
  4. Select gates_workshop_env.
If the environment does not appear:
  1. Open the Command Palette.
  2. Run Python: Select Interpreter.
  3. Select gates_workshop_env.

8. Install Node.js

Download the latest LTS version:

https://nodejs.org/

Windows

Run the installer and accept the default options.

macOS

Run the installer or install using Homebrew:

brew install node

Verify:

node --version
npm --version

9. Final Verification

conda activate gates_workshop_env

python --version

pip --version

node --version

npm --version

If all commands return version numbers and your notebook kernel is set to gates_workshop_env, your environment is ready for the workshop.
